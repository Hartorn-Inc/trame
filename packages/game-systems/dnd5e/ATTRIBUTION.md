# Attribution

The `@trame/game-system-dnd5e` package ships rules content (spells, monsters, magic items, classes, species, backgrounds, feats, conditions and equipment) taken from the System Reference Document 5.2.1, with a few entries from the System Reference Document 5.1 where SRD 5.2.1 has no equivalent (marked `source: "srd-5.1"`). Both documents are licensed under CC-BY-4.0. Any product that displays or distributes this content must show the following notice:

The SRD 5.2.1 is licensed under the Creative Commons Attribution 4.0 International License, available at https://creativecommons.org/licenses/by/4.0/legalcode. It also includes material taken from the System Reference Document 5.1 ("SRD 5.1") by Wizards of the Coast LLC and available at https://dnd.wizards.com/resources/systems-reference-document. The SRD 5.1 is licensed under the Creative Commons Attribution 4.0 International License available at https://creativecommons.org/licenses/by/4.0/legalcode.

The same text is available as data, so applications render it without copying it:

- `SRD_521_ATTRIBUTION` and `CompendiumResolver.getAttribution()` in `src/compendium.ts` (synchronous, no pack loading needed);
- `attribution` in `system.json`;
- `attribution` in `packs/manifest.json`, next to the license, source pin and pack checksums.

A test keeps these four copies identical.

## Generated packs

`packs/spells.json`, `packs/monsters.json` and `packs/magic-items.json` are generated by `scripts/generate-srd-content.ts` (`make srd-content`) from the Open5e `srd-2024` dataset ([open5e/open5e-api](https://github.com/open5e/open5e-api), tag `v2.2.3`, commit `0692d64c1438c848c1da11fbed2d84014b131452`). Open5e transcribes the SRD 5.2.1; the generator checks the sha256 of every input file listed in `packs/manifest.json` and applies the corrections in `scripts/open5eCorrections.ts`, each verified against the SRD 5.2.1 PDF.

The generated packs contain SRD 5.2.1 material only.
