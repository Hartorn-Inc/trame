# Domain Documentation Layout

TRAME uses a **single-context** domain documentation layout:

1. `GLOSSARY.md` at the repository root defines all ubiquitous domain terms (`TrameCommand`, `TableRoomActor`, `BVH`, `GameSystemPack`, `derivedDAG`, `VisibilityChannel`, `FogLayer`, `Idle-Lease`).
2. `ARCHITECTURE.md` and `docs/specs/01-TABLE-SPEC.md` .. `04-RUNTIME-AND-DEDICATED-HOSTING.md` define the complete system specifications.
3. `docs/adr/` records architectural decision records.
