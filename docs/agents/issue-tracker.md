# Issue Tracker — GitHub Issues (`Hartorn-Inc/trame`)

Issues and Wayfinder maps live in GitHub Issues on `Hartorn-Inc/trame`, accessed via the `gh` CLI.

- **Create issue**: `gh issue create --repo Hartorn-Inc/trame --title "..." --body "..." --label "..."`
- **View issue**: `gh issue view <num> --repo Hartorn-Inc/trame --comments`
- **List issues**: `gh issue list --repo Hartorn-Inc/trame`
- **PRs as a request surface**: off.
