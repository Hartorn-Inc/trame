# Triage & Wayfinder Labels (`Hartorn-Inc/trame`)

| Role | Label | Description |
| :--- | :--- | :--- |
| Needs triage | `needs-triage` | Unreviewed issue awaiting scoping |
| Needs info | `needs-info` | Blocked on human clarification |
| Ready for agent | `ready-for-agent` | Fully specified vertical slice ready for EPURE (`/epure plan` / `/epure approve`) |
| Ready for human | `ready-for-human` | Critical architecture / foundation slice owned by the primary architect + human |
| Won't fix | `wontfix` | Out of scope |
| Wayfinder Map | `wayfinder:map` | Master architecture & decision map index |
| Wayfinder Research | `wayfinder:research` | AFK research ticket resolved on a `research/<name>` branch |
| Wayfinder Prototype | `wayfinder:prototype` | HITL throwaway logic or UI prototype (`?variant=`) |
| Wayfinder Grilling | `wayfinder:grilling` | HITL design interview & domain modeling decision |
| Wayfinder Task | `wayfinder:task` | Prerequisite task unblocking a decision |
